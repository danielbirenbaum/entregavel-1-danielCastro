# Primeiro trabalho entregável para o processo seletivo da UFRJ Harpea

## Como usar?

* Instale o projeto em seu computador via git clone:

```bash 
git clone https://github.com/danielbirenbaum/entregavel-1-danielCastro.git
```

* Digite o comando para executar missao.py

```bash 
python3 src/missao.py
```

* Digite os dados do robô e receba a análise desejada! Ex:

```bash 
Digite o valor da bateria atualmente (%): <Valor tipo float> 
```

## Observações

* Os comandos pedidos a serem explicitados, ls e pwd, se encontram apenas na img1.png

* Apesar de não ser pedido no documento do enunciado, criei um tratamento de excessões para valores fora do padrão (por exemplo string quando o input deveria ser float).
